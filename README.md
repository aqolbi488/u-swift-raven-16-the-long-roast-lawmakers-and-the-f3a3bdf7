# The Long Roast: Lawmakers and the File They Cannot Convert

One satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF.

`main.ts` writes the sentence to `/output/entry.txt`. It is deterministic — the same single sentence on every run — with no network, no input and no secrets.

## Run it

```sh
/home/hatch/workspace/tools/node22/bin/node main.ts
```

Then read `/output/entry.txt`.
